Phoenix continuity and recovery
Review before restore

Recovery requires independently durable encrypted Continuum backups, approved key recovery, and a new verified device. The original device can be unavailable.

Restore eligible data and checkpoints

Verify signatures and ciphertext, decrypt through the authorized native host, review staged user data, then explicitly activate a restore. This preview does not access or store any real backup.

The LeeWay user journey

One account. One extension product. Your work stays yours.

01 / SET UP ONCE

Establish My LeeWay

Authenticate and approve the first Device Bridge installation. Select authorized recovery methods and backup scopes. Keep existing identity and permission authorities intact.

02 / ADD DEVICES

Bring a new device online

Open the extension or a trusted recovery portal, sign in to the existing account, approve fresh device credentials, and install the signed LeeWay Node without rebuilding the account.

03 / RECOVER ANYWHERE

Pick up where you left off

Inspect eligible encrypted backups and Agent Lee checkpoints on replacement hardware. Authorize restoration and retain your chosen local/cloud service configuration where supported.

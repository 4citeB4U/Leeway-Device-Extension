    How the connection works

    1. Install the approved LeeWay native companion for the device's operating system, where required.
    2. Install the approved browser extension once from its official store, on browsers that support it.
    3. Sign in with the existing Zitadel-backed LeeWay account. Approve this device's separate passport and capability grants. Your permitted Tablet and applications follow the account; locally dependent functions use qualified native adapters.

    Platform limitations

    Chrome on Android does not run desktop Chrome extensions. On Android, the signed LeeWay companion must provide the original Device Bridge connection and the Tablet is the interface. Apple's Safari extension requires an approved containing app. Unsupported capabilities remain unavailable rather than being simulated.

    GitHub is the canonical source and version history. Store-signed, production-qualified packages are published separately after the original Bridge and release gates pass. GitHub source builds alone do not imply a working device connection.

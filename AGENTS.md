# LeeWay Device Extension — Contributor Admission

**This repository is the W01 Universal Extension PRODUCT HOME.** Its initial source is documentation and a static website only. Do not install a native host, grant privileges, enable cloud recovery, collect user data or migrate executable source on the strength of the homepage.

1. [LeeWay Standards — governing laws](https://github.com/4citeB4U/LeeWay-Standards/blob/main/Docs/governance/LEEWAY-CANONICAL-ENGINEERING-LAWS.md) and [R01–R25](https://github.com/4citeB4U/LeeWay-Standards/blob/main/standards/PERMANENT-ENGINEERING-RULES.md).
2. [LeeWay Engineering](https://github.com/4citeB4U/LeeWay-Engineering), approved W01 mission and active Device Bridge [issue #109](https://github.com/4citeB4U/LEEWAY-DEVICE-BRIDGE/issues/109), exact source SHA, last clean checkpoint and outstanding acceptance gate.
3. [Receipt Authority](https://github.com/4citeB4U/Receipt-Authority) — actual custody, not synthetic receipts; [Agent Skills](https://github.com/4citeB4U/LeeWay-Agent-Skills/blob/main/AGENTS.md) portability and scope controls.
4. Existing Device Bridge extension source drafts [PR #120](https://github.com/4citeB4U/LEEWAY-DEVICE-BRIDGE/pull/120) and [PR #121](https://github.com/4citeB4U/LEEWAY-DEVICE-BRIDGE/pull/121), plus Phoenix [PR #124](https://github.com/4citeB4U/LEEWAY-DEVICE-BRIDGE/pull/124).

## Architecture

- **Product/presentation:** This repository, after reviewed adoption.
- **Native device execution and passports:** Original Device Bridge.
- **Owner authentication and grants:** ZITADEL + original Runtime Fabric.
- **Continuity/recovery:** Continuum encrypted snapshots and approved durable replicas, explicit owner restore.
- **Evidence:** Independent Veritas, original Receipt Authority and authorized Learning Ledger.
- **Source migration:** A single owner-approved extension release lineage only. Preserve the original Device Bridge code and PR history until reconciled; never mirror conflicting browser/native implementations as two independently shipped releases.

## Non-negotiable gates

The public page may advertise design intent only and must never simulate a completed login, device enrollment, backup, or update. Run the home-source tests and preserve CI outputs. Browser source test != installed extension != enrolled native host != physical device operation != qualified recovery != production admission. Ensure owner-to-owner isolation and device-specific authorization. Treat local host paths as observations, never universal identities. Do not use wildcard CORS or resurrect the old 43117 command relay.

Apply the full 12-stage engineering loop and report evidence FOR and AGAINST, exact SHA, approved scope, negative security tests, real poststate, original receipt references, independent Veritas status, and rollback. Continue W01 until physical one-onboarding, second-device enrollment and owner-reviewed restore pass; documentation alone never closes the mission.
